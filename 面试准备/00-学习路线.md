## 项目全局数字（面试可直接引用）

- 代码规模：`src/main/java` 下 **500 个 Java 文件，约 5.5 万行**，25 个一级包
- 内置工具：**20 个**（注意：旧版简历写 19，口径以 `ToolNames.java` 为准）
- Eval case：**22 个**（14 个 common 真实工程任务 + 3 个 longrun + 5 个框架 selftest）
- 技术底座：Java 21（Virtual Threads / Record / Sealed）、Maven、零 Agent 框架依赖

## ⚠️ 面试红线（不要说出口的话)

1. 不要说"上下文压缩有 token 软/硬双阈值"——代码里只有一个显式软阈值（`CompactBudget` = 200k × 0.85），硬限是 provider 侧隐式拒绝。
2. 不要说"Full 压缩是 Map-Reduce 摘要"——实际是单次整体摘要。
3. 不要报评测通过率数字——仓库里目前只有 selftest 跑分记录，没有真实模型端到端跑分。说法建议："自建了 22 个 case 的端到端评测框架，其中 17 个真实工程任务，评测跑在 Docker 网络隔离环境里。"
